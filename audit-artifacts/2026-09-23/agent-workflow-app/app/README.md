# Harbor Notes

A local validation app built with BrainHalf's actual TypeScript starter, SQLite backend generator and uploaded-asset module generator. This fixture was assembled locally; it was not generated by a live AI request.

Includes account registration, login/logout, private notes, create/edit/delete, search, form errors, and an uploaded PNG. The backend persists data in SQLite and scopes notes to each account. It does not simulate successful API responses.

## Run

Requires Node.js 22.18+ and npm. SQLite emits an experimental-feature warning on Node 22.

```sh
npm install
npm run db:migrate
npm run dev:api
```

In another terminal:

```sh
npm run dev -- --host 127.0.0.1 --port 5173
```

Open `http://localhost:5173`. The frontend proxies `/api` to the backend on port 3001. If you change the frontend origin, set `APP_ORIGIN` in `server/.env` to match. See `server/README.md` for deployment requirements.

## Check

```sh
npm run build
npm run typecheck:api
npm run test:handlers
```

The handler check exercises real Node request handlers, SQLite and the typed frontend API client without opening a listener. It creates an isolated temporary database, removes it afterward, and writes `../handler-results.json`. Its image check compares against the original upload's SHA-256 digest.

`npm run test:api` also tests the HTTP listener. That check and browser interactions remain pending in the current restricted environment. Builds and handler checks do not establish that live hosting, AI generation or browser interactions work end to end.
